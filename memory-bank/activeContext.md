## Active Decisions and Considerations
- Using Rust for backend due to performance and safety benefits
- Vue.js for frontend due to its reactivity and component-based architecture
- SQLite for simplicity in development and deployment
- JWT-based authentication for secure API access
- Anilist API integration for anime data

## Important Patterns and Preferences
- Following MVC pattern in backend
- Component-based architecture in frontend
- Type-safe programming in both layers
- RESTful API design principles
- Responsive design for mobile-first approach
- Tests in the same file as the code being tested

## Learnings and Project Insights
- The project has a well-defined structure with clear separation of concerns
- Both backend and frontend are using modern, efficient technologies
- The Anilist integration will be a key feature requiring proper rate limiting
- Mobile responsiveness is a critical requirement based on the existing code
- The project uses TypeScript for type safety in frontend development
