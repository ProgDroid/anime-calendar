# Project Brief: Anime Calendar

## Overview
Anime Calendar is a web application that allows users to track anime series and their episodes across different calendars. Users can create personal calendars, add anime items from Anilist, and manage their viewing schedules.

## Core Features
- User authentication (login/register)
- Personal calendar management
- Anime item browsing from Anilist API
- Calendar synchronization and viewing
- Episode tracking and scheduling

## Technical Stack
- **Backend**: Rust with Actix Web
- **Frontend**: Vue.js with TypeScript and Tailwind CSS
- **Database**: Postgres
- **API**: RESTful API with authentication
- **External Integration**: Anilist API for anime data

## Goals
1. Create a functional calendar application for anime tracking
2. Implement user authentication and authorization
3. Build a responsive frontend with Vue.js
4. Integrate with Anilist API for anime data
5. Provide a clean, intuitive user interface

## Target Audience
Anime fans who want to organize and track their viewing schedules across multiple calendars.

## Success Metrics
- Users can successfully register and login
- Users can create and manage personal calendars
- Users can browse and add anime items to calendars
- Calendar views display correctly on both desktop and mobile
